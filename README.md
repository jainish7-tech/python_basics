## 📝 Practice Questions

### 🔹 Variables
1. What is the difference between a variable and a constant in Python?
2. Swap two variables without using a third variable.
3. What does `x is y` check — value or identity? Predict output for `x=100, y=100` vs `x=1000, y=1000`.
4. Assign `a=1, b=2, c=3` in one line and print their sum.

---

### 🔹 Data Types
1. List the 5 built-in data types in Python with one example each.
2. What is the difference between `int` and `float`?
3. Why is `bool` a subclass of `int`? What does `True + True` return?
4. What does `type()` return for `[1,2,3]` vs `(1,2,3)`?

---

### 🔹 Operators
1. What is the difference between `/` and `//` in Python?
2. What does `**` do? What is `2 ** 10`?
3. What is the difference between `==` and `is`?
4. Evaluate: `5 > 3 and 2 < 1` — what does this return and why?

---

### 🔹 String Handling
1. How do you reverse a string using slicing?
2. What is the difference between `.find()` and `.index()`?
3. How do you check if a string is a palindrome?
4. What does `'hello'.upper().replace('L','X')` output?

---

### 🔹 If-Else
1. Write a program to check if a number is positive, negative, or zero.
2. What is a ternary (one-line) if-else? Give an example.
3. Write an if-elif-else chain to grade marks: A/B/C/F.
4. Can you use `if` without `else`? Give an example where it makes sense.

---

### 🔹 Type Casting
1. What is the difference between implicit and explicit type casting?
2. What does `int('42abc')` do — explain the error.
3. Convert the string `'3.14'` to a float and then to an int. What is the final value?
4. Why does `str(True)` return `'True'` and `int(True)` return `1`?

---

### 🔹 Loops
1. What is the difference between a `for` loop and a `while` loop?
2. Print the multiplication table of 7 using a `for` loop.
3. Write a `while` loop that keeps halving a number until it's below 1.
4. What does `range(1, 10, 2)` produce? List the values.

---

### 🔹 Match Case
1. What Python version introduced `match-case`? How is it different from `if-elif`?
2. Write a `match-case` block for HTTP status codes: 200, 404, 500, and a default.
3. Can `match-case` match multiple patterns in one `case`? Show an example.
4. What does the `_` pattern mean in `match-case`?

---

### 🔹 break / continue / pass
1. What is the difference between `break` and `continue`?
2. Write a loop that prints 1–10 but skips all even numbers using `continue`.
3. Write a loop that stops immediately when it hits the number 7 using `break`.
4. What does `pass` do and when would you use it in a function or loop?

---

### 🔹 Functions & Arguments
1. What is the difference between positional, keyword, and default arguments?
2. What do `*args` and `**kwargs` do? Give one example each.
3. Write a function that returns the factorial of a number recursively.
4. Can a function return multiple values? If yes, what data type is the result?

---

### 🔹 Lists & Methods
1. What is the difference between `.append()` and `.extend()`?
2. How do you remove duplicates from a list without using `set()`?
3. What does `list.sort()` do vs `sorted(list)`? What's the key difference?
4. Reverse a list in-place and also using slicing — what's the difference?

---

### 🔹 Tuples & Methods
1. Why are tuples immutable and when should you prefer them over lists?
2. What does `tuple.count()` and `tuple.index()` do?
3. Can a tuple contain a list inside it? Can you modify that inner list?
4. How do you unpack a tuple into separate variables? Show an example.
